# Software-FJ

El presente trabajo tiene como objetivo desarrollar un sistema de gestión para la empresa Software FJ, 
diseñado para administrar de manera organizada sus clientes, servicios (reservas de salas,
alquiler de equipos y asesorías especializadas) y solicitudes de reserva. 

## Requisitos
* Python
* Vs CODE

## Cómo ejecutarlo
1. Clonar el repositorio.
2. Entrar en la carpeta del proyecto "cd Software-FJ"
3. Ejecutar `python main.py` en la terminal.
